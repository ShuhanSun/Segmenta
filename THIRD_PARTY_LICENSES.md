# Third-party software

Segmenta's runtime, offline installer, and test suite use only the Python
standard library. Python is distributed under the Python Software Foundation
License. The optional packaging backend declared in `pyproject.toml` is
setuptools, distributed under the MIT license; it is not required by the
documented offline installation path.

No third-party source code, model weights, datasets, services, or paid APIs are
included in this repository.
